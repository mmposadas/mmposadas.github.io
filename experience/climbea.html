Climbea · Data Scientist

Automatización de extracción y análisis de datos sociales

Pipeline de minería de datos de Twitter/X sobre 23 Parques Nacionales europeos, con NLP y dashboards en Power BI — cuyos datasets alimentaron un capítulo de libro académico publicado.

PythonNLPPower BICrontab

El reto

En colaboración con la Universidad de Almería, el objetivo era entender patrones de comportamiento e interacción en Parques Nacionales europeos a partir de datos no estructurados de redes sociales, sin un proceso automatizado que los recopilara y analizara de forma periódica.

Mi aportación

Diseñé e implementé un pipeline de recolección de datos vía Twitter API cubriendo las cuentas oficiales de 23 Parques Nacionales europeos, programando su ejecución periódica con crontab. Procesé y analicé aproximadamente un año de actividad con técnicas de NLP, estudiando sentimiento, engagement de audiencia y patrones de interacción geográfica, y modelé los resultados en paneles interactivos de Power BI aplicando transformaciones con Power Query. Los datasets analíticos resultantes sirvieron como fuente de datos para un capítulo de libro publicado sobre estrategias de redes sociales en áreas protegidas.

Detalle del proceso

1

Extracción vía Twitter API

Pipeline en Python para recolectar datos de las cuentas oficiales de 23 Parques Nacionales, programado con crontab.

2

Análisis de sentimiento y NLP

Procesamiento de texto no estructurado para extraer sentimiento y métricas de engagement.

3

Mapeo geográfico

Identificación de patrones de comportamiento por ubicación en distintos Parques Nacionales europeos.

4

Dashboards en Power BI

Transformación de datos con Power Query y modelado de paneles interactivos para el equipo de investigación.
